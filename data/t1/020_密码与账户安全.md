# 密码与账户安全

## 一、密码设置规则

### 1.1 密码要求
| 类型 | 要求 |
|------|------|
| 登录密码 | 8-20位，字母+数字 |
| 支付密码 | 6位数字 |
| 安全问题 | 自行设置，用于找回 |

### 1.2 密码修改
- 登录密码：可在设置中修改
- 支付密码：需验证原密码
- 每月限修改3次支付密码

### 1.3 密码找回
| 方式 | 操作步骤 |
|------|---------|
| 手机验证码 | 输入注册手机号，接收验证码 |
| 邮箱验证 | 输入注册邮箱，接收链接 |
| 人工申诉 | 提供身份证明等材料 |

## 二登录安全

### 2.1 异地登录
- 新设备首次登录需验证
- 可在设置中管理可信设备
- 异常登录会触发风控

### 2.2 登录限制
| 情况 | 限制 |
|------|------|
| 密码错误5次 | 锁定30分钟 |
| 频繁更换设备 | 需短信验证 |
| 异常登录 | 可能被冻结 |

### 2.3 登录设备管理
- 可查看所有登录设备
- 可远程退出其他设备
- 可设置可信设备免验证

## 三、支付安全

### 3.1 支付验证
- 小额支付：仅需密码
- 大额支付：密码+短信验证码
- 陌生设备：密码+短信验证码

### 3.2 安全设置
| 设置项 | 说明 |
|-------|------|
| 支付密码 | 独立于登录密码 |
| 指纹支付 | 需设备支持 |
| 面部支付 | 需设备支持 |
| 支付限额 | 可自行调整 |

### 3.3 风险控制
以下情况可能拦截支付：
- 异地支付
- 大额支付
- 短时间多笔支付
- 账户信息异常

## 四、账户被盗处理

### 4.1 被盗迹象
- 账户信息被修改
- 未知订单出现
- 余额异常变动
- 收货地址被修改

### 4.2 紧急处理
1. 立即修改密码
2. 冻结账户
3. 联系客服
4. 报警处理

### 4.3 赔付申请
以下情况可申请赔付：
- 非本人操作的订单
- 账户被盗且非主观过失
- 系统漏洞导致损失

## 五、安全建议

### 5.1 密码建议
- 密码要足够复杂
- 不要使用相同密码
- 定期更换密码
- 不要在不安全场所输入密码

### 5.2 账户保护
- 开启两步验证
- 设置支付密码
- 绑定手机和邮箱
- 定期查看登录记录

### 5.3 谨防诈骗
- 不要相信客服索要密码
- 不要点击陌生链接
- 不要透露验证码
- 发现异常立即联系客服
