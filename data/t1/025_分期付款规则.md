# 分期付款规则

## 一、分期付款概述

### 1.1 支持的分期类型
| 类型 | 提供方 | 期数选择 |
|------|-------|---------|
| 花呗分期 | 支付宝花呗 | 3/6/12期 |
| 信用卡分期 | 各银行信用卡 | 3/6/12/24期 |
| 任性付 | 苏宁任性付 | 3/6/12期 |
| 京东白条 | 京东白条 | 3/6/12/24期 |

### 1.2 分期手续费
| 期数 | 花呗 | 信用卡(参考) |
|------|-----|------------|
| 3期 | 2.5% | 2-3% |
| 6期 | 4.5% | 4-5% |
| 12期 | 8.8% | 8-10% |
| 24期 | 15% | 15-18% |

### 1.3 分期门槛
- 单笔订单金额需达到一定门槛
- 视商品和商家活动而定
- 部分商品不支持分期

## 二、分期申请流程

### 2.1 申请步骤
```
选择商品 → 选择分期 → 验证信用 → 确认分期 → 完成支付
```

### 2.2 资格验证
- 花呗：需开通花呗服务
- 信用卡：需有可用额度
- 任性付：需通过任性付审核

### 2.3 分期确认
- 确认手续费金额
- 确认每期还款金额
- 确认还款日

## 三、分期还款

### 3.1 还款日期
| 类型 | 还款日 |
|------|-------|
| 花呗 | 每月9/10日 |
| 信用卡 | 以银行账单日为准 |
| 任性付 | 每月固定日 |

### 3.2 还款方式
- 自动扣款（推荐）
- 主动还款（APP操作）
- 合并还款（多笔合并）

### 3.3 逾期处理
- 逾期将产生滞纳金
- 影响个人信用记录
- 可能被限制分期功能

## 四、分期退货退款

### 4.1 退货流程
1. 申请退货并退款
2. 商家确认收货
3. 分期额度恢复
4. 已付首期退款至账户

### 4.2 退款金额计算
- 退款金额 = 实际支付金额
- 已付手续费不退还
- 退款用于冲抵后续账单

### 4.3 部分退款
- 按比例分配退款金额
- 首期多付部分优先退还
- 分期手续费不退还

## 五、分期提前还款

### 5.1 提前还款规则
- 可随时提前还款
- 还款金额 = 剩余本金 + 剩余手续费
- 部分提前还款可减手续费

### 5.2 提前还款流程
1. 在分期页面选择提前还款
2. 计算提前还款金额
3. 确认并完成支付
4. 分期关闭
