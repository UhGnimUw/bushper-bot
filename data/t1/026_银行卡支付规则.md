# 银行卡支付规则

## 一、支持的银行卡

### 1.1 借记卡
| 银行 | 限额 | 备注 |
|------|------|------|
| 工商银行 | 单笔5万/日10万 | - |
| 农业银行 | 单笔5万/日10万 | - |
| 中国银行 | 单笔5万/日10万 | - |
| 建设银行 | 单笔5万/日10万 | - |
| 招商银行 | 单笔5万/日10万 | - |

### 1.2 信用卡
| 银行 | 单笔限额 | 日限额 |
|------|---------|-------|
| 各银行信用卡 | 视银行额度 | 视银行设定 |

### 1.3 其他银行卡
- 地区性银行（城商行/农信社）
- 外资银行
- 部分农商银行

## 二、支付流程

### 2.1 借记卡支付
```
选择银行卡 → 输入卡号 → 验证手机号 → 输入短信验证码 → 支付成功
```

### 2.2 信用卡支付
```
选择信用卡 → 输入卡号/有效期/CVV → 验证手机号 → 支付成功
```

### 2.3 快捷支付
- 已绑定的银行卡可直接支付
- 无需每次输入卡号
- 需验证支付密码

## 三、安全验证

### 3.1 验证方式
| 金额 | 验证方式 |
|------|---------|
| 小额 | 支付密码 |
| 中额 | 密码+短信验证码 |
| 大额 | 密码+短信+人脸识别 |

### 3.2 短信验证码
- 验证码5分钟内有效
- 验证码不可泄露给他人
- 连续验证失败5次锁定

## 四、退款规则

### 4.1 退款时限
| 银行类型 | 退款到账 |
|---------|---------|
| 借记卡 | 1-3个工作日 |
| 信用卡 | 1-5个工作日 |
| 地区银行 | 3-7个工作日 |

### 4.2 退款查询
- 银行卡退款可查询银行流水
- 部分银行退款显示为"充值"
- 超过时限未到账可联系客服

## 五、限额说明

### 5.1 支付限额
| 银行卡类型 | 单笔限额 | 日累计限额 |
|-----------|---------|-----------|
| 普通借记卡 | 1-5万 | 5-10万 |
| 网银盾用户 | 10-50万 | 50-100万 |
| 信用卡 | 银行额度 | 固定额度 |

### 5.2 限额调整
- 可在银行设置中调整
- 部分限额由银行自动判定
- 大额支付建议分多笔
