# 微信/支付宝支付规则

## 一、微信支付规则

### 1.1 支付方式
| 方式 | 说明 |
|------|------|
| 扫码支付 | 微信扫二维码支付 |
| APP支付 | APP内调起微信支付 |
| H5支付 | 手机浏览器支付 |
| 小程序支付 | 微信小程序内支付 |

### 1.2 支付限额
| 用户类型 | 单笔限额 | 日限额 |
|---------|---------|-------|
| 未实名用户 | 1000元 | 1000元 |
| 实名用户 | 5万元 | 10万元 |
| 高级实名 | 更高 | 更高 |

### 1.3 到账时间
- 微信支付即时到账
- 退款1-3个工作日到账

## 二、支付宝支付规则

### 2.1 支付方式
| 方式 | 说明 |
|------|------|
| 余额支付 | 支付宝余额付款 |
| 银行卡支付 | 绑定银行卡付款 |
| 花呗支付 | 蚂蚁花呗付款 |
| 积分支付 | 支付宝积分抵现 |

### 2.2 支付限额
| 支付方式 | 单笔限额 | 日限额 |
|---------|---------|-------|
| 余额 | 20万/笔 | 20万/日 |
| 银行卡 | 视银行卡限额 | 视银行设定 |
| 花呗 | 花呗额度 | 花呗额度 |

### 2.3 到账时间
- 支付宝支付即时到账
- 退款即时或1-3个工作日

## 三、常见问题

### 3.1 支付失败
| 原因 | 解决方法 |
|------|---------|
| 余额不足 | 充值或换支付方式 |
| 风控拦截 | 验证身份后重试 |
| 超过限额 | 分多笔或换方式 |
| 网络问题 | 检查网络后重试 |

### 3.2 重复扣款
- 支付失败但已扣款会自动退回
- 1-3个工作日到账
- 如未退回联系客服

### 3.3 退款查询
- 微信支付退款在微信支付账单查看
- 支付宝退款在支付宝账单查看
- 退款记录显示为"退款"

## 四、安全提示

### 4.1 谨防诈骗
- 不要相信"退款需要转账"的说辞
- 官方不会索要支付密码
- 不要点击陌生链接支付

### 4.2 账户安全
- 开启支付密码
- 开启指纹/刷脸支付
- 定期查看支付记录
- 异常支付立即联系客服
