# 账户注销与数据处理

## 一、账户注销规则

### 1.1 注销条件
| 条件 | 说明 |
|------|------|
| 无进行中订单 | 所有订单已完结 |
| 无未完结售后 | 退款/售后已处理 |
| 余额为零 | 账户余额已提现 |
| 无积分/优惠券 | 积分已使用/过期 |

### 1.2 注销流程
```
申请注销 → 7天冷静期 → 确认注销 → 账户删除 → 完成
```

### 1.3 注销影响
- 账户永久删除不可恢复
- 订单记录按法规保留
- 个人信息全部删除
- 会员权益全部失效

## 二、数据保留

### 2.1 法定保留
| 数据类型 | 保留时间 | 说明 |
|---------|---------|------|
| 订单记录 | 3年 | 财税法规要求 |
| 交易凭证 | 3年 | 财税法规要求 |
| 售后记录 | 3年 | 消费者权益保护 |

### 2.2 删除数据
| 数据类型 | 处理方式 |
|---------|---------|
| 个人信息 | 永久删除 |
| 浏览记录 | 永久删除 |
| 收货地址 | 永久删除 |
| 联系方式 | 永久删除 |

## 三、账户被盗处理

### 3.1 被盗迹象
| 迹象 | 说明 |
|------|------|
| 未知登录 | 异地/异常设备登录 |
| 信息篡改 | 密码/手机被改 |
| 异常订单 | 未知订单出现 |
| 余额变动 | 余额异常减少 |

### 3.2 紧急处理
1. 立即修改密码
2. 冻结账户
3. 联系客服
4. 报警处理

## 四、未成年人账户

### 4.1 账户限制
- 14岁以下需监护人同意
- 14-18岁有限制使用
- 某些功能需成年后开通

### 4.2 消费限制
- 大额消费需监护人确认
- 某些商品禁止未成年人购买
- 游戏充值有时间限制
