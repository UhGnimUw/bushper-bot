# 订单状态与修改规则

## 一、订单状态说明

### 1.1 订单生命周期
| 状态 | 说明 | 可执行操作 |
|------|------|----------|
| 待支付 | 订单已创建，等待用户付款 | 取消订单、修改地址、修改商品 |
| 已支付 | 用户已完成付款，等待发货 | 取消订单（需退款）、修改地址（部分情况） |
| 已发货 | 商品已发出，等待收货 | 查看物流、确认收货、申请退货 |
| 已签收 | 用户已确认收货 | 申请退货、申请售后 |
| 已取消 | 订单已取消 | 无 |

### 1.2 地址修改规则

#### 已发货状态
**核心规则：已发货订单不允许修改收货地址**

- 商品一旦发出，物流信息已绑定快递公司系统
- 快递公司无法中途更改收货地址
- 如需更改，只能取消当前订单重新下单（已发货商品需等收货后退货）

**例外情况：**
- 地址变更涉及疫情管控区域，可联系客服特殊处理
- 同城转寄服务（需自行联系快递公司，可能产生额外费用）

#### 已支付未发货
- 可在"我的订单"中自助修改收货地址
- 仅限修改街道、门牌号等详细地址信息
- 收货人姓名、手机号不可修改（涉及账户安全）

### 1.3 商品修改规则

**待支付状态：**
- 可在订单详情页增减商品数量
- 可更换商品规格（如颜色、尺码）
- 不可更换商品品类

**已支付后：**
- 所有商品信息不可修改
- 如需更换，只能取消订单重新下单

### 1.4 取消订单规则

| 状态 | 取消方式 | 退款方式 | 退款时限 |
|------|---------|---------|---------|
| 待支付 | 自助取消 | 无需退款 | - |
| 已支付-待发货 | 申请取消 | 原支付方式退回 | 1-3个工作日 |
| 已发货 | 拒收后退货 | 收到退货后退款 | 3-5个工作日 |

**违约取消：**
- 用户超过60天未付款，订单自动取消
- 恶意取消订单超过5次，账户受限

## 二、订单时效规则

### 2.1 订单保留期限
- 待支付订单保留时间为**30分钟**
- 超时未支付自动取消，商品库存释放
- 已支付订单无限期保留，直至用户操作

### 2.2 发货时效承诺
| 商品类型 | 发货时效 | 赔付规则 |
|---------|---------|---------|
| 现货商品 | 48小时内发货 | 超时可索赔10元优惠券 |
| 预售商品 | 按页面承诺时间发货 | 详情见预售规则 |
| 海外直邮 | 5-7个工作日发货 | 超时赔付50元 |

### 2.3 自动确认收货
- 物流显示签收**15天后**自动确认收货
- 如未收到货，请在15天内点击"未收到货"延长确认时间
- 超过30天未确认且无物流异常，视为已收货

## 三、订单查询与凭证

### 3.1 订单查询
用户可通过以下方式查询订单：
- APP/小程序：我的→全部订单
- 网页端：我的订单→订单详情
- 客服热线：提供订单号查询

### 3.2 订单凭证
订单凭证包括：
- 电子订单号（用于查询和联系客服）
- 电子收据（可在订单详情页下载）
- 增值税发票（可申请开票）

### 3.3 订单合并与拆分
- 同一店铺、同一时间的订单可申请合并发货
- 大额订单可能自动拆分为多个包裹发货
- 拆分发货会在物流信息中显示全部快递单号
