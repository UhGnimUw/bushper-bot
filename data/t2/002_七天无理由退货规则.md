# 七天无理由退货规则

## 一、七天无理由退货适用范围

### 1.1 支持七天无理由退货的商品
根据《网络购买商品七日无理由退货暂行办法》，以下商品支持七天无理由退货：

| 商品类别 | 示例 | 说明 |
|---------|------|-----|
| 服装鞋帽 | 上衣、裤子、鞋子、帽子 | 已试穿不影响二次销售 |
| 家用电器 | 电视、冰箱、洗衣机 | 电器类需保留完整包装 |
| 数码产品 | 手机、电脑、相机 | 已激活使用可影响退货 |
| 办公用品 | 打印机、复印机 | 需保留全部配件 |
| 运动户外 | 健身器材、球类用品 | 已使用可影响退货 |
| 母婴用品 | 奶粉、尿裤、婴儿车 | 食品类需未开封 |

### 1.2 不支持七天无理由退货的商品

**核心规则：已签收/已拆封且影响二次销售的商品可能不支持无理由退货**

以下商品不适用七天无理由退货：

| 商品类别 | 不适用原因 |
|---------|-----------|
| 定制商品 | 根据用户特殊要求制作 |
| 鲜活易腐商品 | 生鲜食品保质期短 |
| 拆封的视听制品 | 软件、影碟等已授权 |
| 个人定制类 | 刻字、印名等专属定制 |
| 内衣、泳装、睡衣 | 涉及个人卫生 |
| 进口保税商品 | 海关监管要求 |

### 1.3 "签收"的理解
- **自提点签收**：自提点取货即为签收
- **快递柜签收**：放入快递柜即为签收
- **代收签收**：代收人签收视为用户本人签收

## 二、七天时效计算

### 2.1 起算时间
- 自**实际签收日期**次日起算
- 物流显示签收日 = 第0天
- 下一个自然日 = 第1天开始

### 2.2 时效示例
| 签收日期 | 最后退货日期 | 说明 |
|---------|------------|------|
| 1月1日签收 | 1月8日24:00前申请 | 共7天 |
| 1月1日下午签收 | 1月8日下午前申请 | 按时间计算 |
| 1月1日签收 | 1月8日内发出即可 | 以快递揽收时间为准 |

### 2.3 特殊期间顺延
- 国家法定节假日期间顺延
- 物流高峰期可能顺延2-3天
- 台风、暴雨等不可抗力期间顺延

## 三、退货流程与要求

### 3.1 自助退货流程
```
申请退货 → 商家审核（24h） → 用户寄回 → 商家收货 → 退款
```

### 3.2 退货包装要求
- 保持商品原有包装完整
- 商品配件、说明书、保修卡齐全
- 外观无磨损、无污渍
- 已安装的商品需恢复原状

### 3.3 退货运费规则

| 退货原因 | 运费承担方 | 说明 |
|---------|-----------|------|
| 商品质量问题 | 商家承担 | 商家原因导致 |
| 错发/漏发 | 商家承担 | 我方失误 |
| 7天无理由退货 | 用户承担 | 个人原因退货 |
| 运输损坏 | 商家承担 | 拍照留证 |

### 3.4 不予退货情况
- 商品已使用且影响二次销售
- 包装已拆封且无法复原
- 商品经改装、改装、磨损
- 随商品附带的赠品未退回
- 超过七天退货期限

## 四、退款规则

### 4.1 退款方式
| 原支付方式 | 退款方式 | 退款时限 |
|-----------|---------|---------|
| 支付宝/微信 | 原路退回 | 3-5个工作日 |
| 银行卡 | 原卡退回 | 3-7个工作日 |
| 礼品卡 | 退回礼品卡余额 | 即时到账 |
| 优惠券 | 不予退回 | 不可恢复 |

### 4.2 退款金额计算
- 退货商品全额退款
- 优惠券不予补偿
- 满减活动按比例分摊
- 赠品未退回需扣除赠品价值

### 4.3 退款状态查询
- 商家收货后1-2个工作日完成退款
- 可在"我的→退款/售后"中查看详情
- 银行卡退款可能受银行处理时间影响

## 五、特殊商品退货

### 5.1 电器类商品
- 电视、冰箱等大件电器需预约上门取件
- 30天内性能故障可换货
- 包装需保留原厂包装

### 5.2 服装类商品
- 试穿不影响退货（不影响二次销售）
- 需保留原包装衣架
- 洗涤过的商品不予退货

### 5.3 化妆品/护肤品
- 已拆封使用但未过期的，可申请部分退款
- 未拆封可全额退货
- 小样/赠品需一同退回

### 5.4 进口商品
- 保税区发货商品退货需退至保税仓
- 跨境直邮商品退货周期较长（约15-20天）
- 可能涉及关税问题
