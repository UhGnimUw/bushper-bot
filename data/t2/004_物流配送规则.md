# 物流配送规则

## 一、配送方式说明

### 1.1 配送方式类型
| 配送方式 | 预计时效 | 运费标准 | 适用地区 |
|---------|---------|---------|---------|
| 普通快递 | 3-7天 | 满99免运费 | 全国大部分地区 |
| 次日达 | 1-2天 | 收费较高 | 主要城市 |
| 当日达 | 当日送达 | 较高 | 部分城市核心区 |
| 同城配送 | 2-4小时 | 按距离计费 | 同城范围 |
| 预约配送 | 用户指定日期 | 标准运费 | 全国 |
| 海外直邮 | 7-15天 | 按重量计费 | 境外地区 |

### 1.2 配送时效说明
- **预计时效**：从商品出库开始计算
- **不包含节假日**：法定节假日顺延
- **特殊情况**：双十一等高峰期可能延迟1-2天

## 二、运费规则

### 2.1 包邮条件
| 会员等级 | 全场包邮门槛 | 特殊商品 |
|---------|------------|---------|
| 普通会员 | 99元 | 部分大件商品除外 |
| 银卡会员 | 79元 | 部分大件商品除外 |
| 金卡会员 | 59元 | 部分大件商品除外 |
| 黑金会员 | 全场包邮 | 无例外 |

### 2.2 运费计算规则
- 首重1kg内按首重价格计费
- 超过首重按续重价格累加
- 部分大件商品按件计费（不论重量）

### 2.3 运费补贴
以下情况可获得运费补贴：
- 商家发错货：商家承担往返运费
- 商品质量问题：商家承担运费
- 物流损坏：商家承担运费

## 三、物流查询

### 3.1 查询方式
- 订单详情页查看物流进度
- 点击快递单号跳转快递官网
- 关注服务号推送物流通知
- 联系客服查询物流详情

### 3.2 物流状态说明
| 状态 | 含义 |
|------|------|
| 商品已发出 | 商家已发货，物品在途 |
| 到达某地 | 物流中转到达某城市 |
| 派送中 | 快递员正在派送 |
| 已签收 | 商品已签收 |
| 拒收 | 收件人拒收 |
| 退回 | 货物被退回商家 |

### 3.3 物流异常处理
| 异常情况 | 用户应对 |
|---------|---------|
| 物流停滞 | 联系商家或快递公司 |
| 快递员不联系 | 可联系客服协助 |
| 物流显示签收但未收到 | 申请退款或要求补发 |
| 包装破损 | 拒收并拍照留证 |

## 四、签收规则

### 4.1 签收验货
- 建议当着快递员面验货
- 发现包装破损可拒收
- 签收后发现问题需在24小时内联系客服

### 4.2 代收规则
- 代收人签收视为本人签收
- 快递柜/驿站取件即为签收
- 同事/家人代收视为本人签收

### 4.3 拒收规则
- 包装破损可直接拒收
- 商品与描述不符可拒收
- 拒收后联系客服处理退款

## 五、大件商品配送

### 5.1 大件认定
符合以下条件为大件商品：
- 单件重量超过30kg
- 长宽高任一项超过1.5米
- 家具、家电等大件商品

### 5.2 大件配送规则
- 需要预约送货上门
- 部分城市支持安装服务（付费）
- 大件不参与满99包邮活动

### 5.3 安装服务
- 热水器、空调等需专业安装
- 安装费用另行收取
- 安装前需确认商品完好

## 六、保税区/海外配送

### 6.1 保税区发货
- 下单后从保税区仓库发货
- 需要实名认证
- 配送时间5-10天

### 6.2 海外直邮
- 从海外仓库直接发货
- 可能需要清关
- 关税由用户承担

### 6.3 海关查验
- 部分商品可能海关查验
- 查验期间物流可能停滞
- 通常3-5个工作日
