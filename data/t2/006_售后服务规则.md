# 售后服务规则

## 一、售后服务类型

### 1.1 售后申请类型
| 类型 | 说明 | 申请时限 | 处理方式 |
|------|------|---------|---------|
| 退货 | 退还商品并退款 | 7天/15天/30天 | 退款至原支付方式 |
| 换货 | 更换同款商品 | 15天/30天 | 换同款新商品 |
| 维修 | 商品维修处理 | 保修期内 | 厂家保修 |
| 退款 | 仅退款不退货 | 7天内 | 退款至原支付方式 |
| 投诉 | 商家服务投诉 | 无限制 | 客服调解处理 |

### 1.2 各场景售后时限
| 商品类型 | 退货时限 | 换货时限 | 保修时限 |
|---------|---------|---------|---------|
| 普通商品 | 7天 | 15天 | 1年 |
| 手机/数码 | 7天 | 15天 | 1年 |
| 大家电 | 7天 | 30天 | 3年 |
| 服装鞋帽 | 7天 | 15天 | 90天 |
| 食品/美妆 | 7天（特殊） | 不支持 | 视商品而定 |

## 二、售后服务流程

### 2.1 申请流程
```
用户提交申请 → 商家审核(24h) → 用户寄回商品 → 商家收货检测 → 退款/换货
```

### 2.2 商家审核标准
商家需在24小时内审核售后申请：
- 工作日：24小时内必审核
- 节假日：最迟72小时内审核
- 逾期未审核自动通过

### 2.3 审核拒绝与申诉
- 商家拒绝后可申请平台介入
- 提供凭证进行申诉
- 平台仲裁为最终裁决

## 三、保修服务规则

### 3.1 保修范围
- 商品本身存在的质量问题
- 非人为因素导致的故障
- 正常使用下的损坏

### 3.2 非保修范围
| 情况 | 说明 |
|------|------|
| 人为损坏 | 摔落、进水、私自拆修 |
| 外观磨损 | 正常使用的外观磨损 |
| 消耗品 | 电池、耗材等 |
| 不可抗力 | 雷击、洪水等 |

### 3.3 保修凭证
- 发票/订单截图
- 商品序列号
- 问题描述及照片
- 检测报告（必要时）

## 四、上门服务规则

### 4.1 上门服务范围
以下商品可申请上门服务：
- 大家电安装/维修
- 卫浴产品安装
- 部分大件商品退换货

### 4.2 上门服务预约
- 需提前1-2天预约
- 预约时间可选择上午/下午
- 师傅上门前会电话确认

### 4.3 上门服务费用
| 服务类型 | 费用说明 |
|---------|---------|
| 质量问题上门 | 商家承担 |
| 退换货上门取件 | 部分由用户承担 |
| 安装服务 | 另行收费 |
| 拆机服务 | 另行收费 |

## 五、特殊商品售后

### 5.1 手机/数码产品
- 7天内可申请退货（已激活影响二次销售）
- 15天内可换货
- 1年内官方保修
- 碎屏险可单独购买

### 5.2 电脑/办公设备
- 7天无理由退货（需未激活）
- 开箱损可立即换货
- 保修期内免费维修
- 正版软件需另行购买

### 5.3 家具/家居
- 大件商品需预约上门安装
- 退货需原包装或等效包装
- 部分家具需自行组装
- 床垫等个人卫生用品拆封不退

### 5.4 珠宝/钟表
- 需提供鉴定证书
- 钻石等奢侈品有专属售后
- 皮具需专业保养

## 六、售后争议处理

### 6.1 争议类型
- 商品损坏责任争议
- 检测结果争议
- 退货时限争议
- 运费承担争议

### 6.2 举证要求
| 争议情况 | 举证方 | 举证内容 |
|---------|-------|---------|
| 商品损坏 | 用户 | 照片/视频 |
| 商家发错 | 用户 | 照片/订单 |
| 商品完好拒退 | 商家 | 检测报告 |
| 包装问题 | 商家 | 开箱视频 |

### 6.3 仲裁结果
- 客服仲裁为最终结果
- 恶意售后将受处罚
- 多次违规将被限制售后权限
