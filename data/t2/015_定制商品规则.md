# 定制商品规则

## 一、定制商品类型

### 1.1 常见定制类型
| 类型 | 示例 | 定制内容 |
|------|------|---------|
| 刻字定制 | 戒指、项链、水杯 | 刻字/刻图案 |
| 印照片 | T恤、抱枕、手机壳 | 照片印刷 |
| 定制尺寸 | 窗帘、服装、鞋子 | 专属尺寸 |
| 颜色定制 | 口红、包包 | 特殊颜色 |
| 礼品定制 | 包装、贺卡 | 专属包装 |

### 1.2 定制流程
```
选择商品 → 提供定制信息 → 确认设计稿 → 生产制作 → 配送
```

## 二、定制规则

### 2.1 定制信息确认
- 定制信息提交后不可修改
- 请仔细核对文字/图案
- 颜色可能会有色差
- 特殊字符可能无法制作

### 2.2 生产周期
| 定制类型 | 生产周期 | 说明 |
|---------|---------|------|
| 刻字饰品 | 3-5天 | 手工制作 |
| 印照片类 | 2-3天 | 印刷加工 |
| 定制服装 | 5-7天 | 生产制作 |
| 大件定制 | 7-15天 | 生产周期长 |

### 2.3 设计稿确认
- 部分商品需确认设计稿
- 确认后开始生产
- 确认前可修改设计
- 超时未确认可能自动确认

## 三、退款退货规则

### 3.1 核心规则
**定制商品一经生产不可退款退货**

### 3.2 例外情况
| 情况 | 处理方式 |
|------|---------|
| 商品质量问题 | 免费返工或退款 |
| 商家制作错误 | 免费重做或退款 |
| 严重色差/损坏 | 协商退款 |

### 3.3 尺寸问题
- 尺寸定制请仔细核对尺码表
- 尺寸误差在合理范围内不可退换
- 明显尺寸偏差可申请维权

## 四、定制限制

### 4.1 内容限制
以下内容不可定制：
- 违法违纪内容
- 侵犯他人权益内容
- 宗教/政治敏感内容
- 淫秽色情内容
- 冒充他人/虚假信息

### 4.2 品牌限制
- 不可定制仿冒品牌logo
- 不可定制商标侵权内容
- 原创设计请提供授权

### 4.3 数量限制
- 定制商品通常单件制作
- 大批量定制需联系客服
- 批量定制价格更优惠

## 五、定制商品售后

### 5.1 质量问题
- 制作问题导致的质量问题可退换
- 需提供照片/视频证据
- 退换货运费由商家承担

### 5.2 非质量问题
- 定制商品非质量问题不可退换
- 手工制作可能有细微差异
- 请以实物为准

### 5.3 售后时效
- 签收后7天内申请售后
- 超时可能无法处理
- 请在收货时立即验货
