# 订单时效规则

## 一、订单创建与支付

### 1.1 订单创建
- 订单创建后保留30分钟
- 超时未支付自动取消
- 取消后商品库存释放

### 1.2 支付时限
| 支付方式 | 支付时限 |
|---------|---------|
| 线上支付 | 30分钟内 |
| 货到付款 | 快递员上门时支付 |
| 分期付款 | 按期支付 |

### 1.3 支付超时
- 超时订单自动关闭
- 已支付但订单关闭会自动退款
- 退款1-3个工作日到账

## 二、发货时效

### 2.1 发货时间
| 商品类型 | 发货时限 |
|---------|---------|
| 现货商品 | 48小时内 |
| 预售商品 | 按承诺时间 |
| 定制商品 | 生产完成后 |

### 2.2 发货通知
- 发货后短信通知
- 订单详情显示快递单号
- 可追踪物流进度

### 2.3 延迟发货
- 延迟可申请赔偿
- 赔偿金额为商品价格5%
- 最高不超过50元

## 三、收货与确认

### 3.1 物流时效
| 配送方式 | 预计时效 |
|---------|---------|
| 普通快递 | 3-7天 |
| 次日达 | 1-2天 |
| 同城配送 | 2-4小时 |

### 3.2 确认收货
- 可手动确认收货
- 物流签收15天后自动确认
- 超时30天自动确认

### 3.3 延长收货
- 未收到货可申请延长
- 最多延长15天
- 申请后商家确认生效

## 四、退款时效

### 4.1 退款处理时间
| 场景 | 处理时间 |
|------|---------|
| 取消订单-待发货 | 即时处理 |
| 退货退款-商家确认收货 | 1-2个工作日 |
| 系统自动退款 | 即时/1个工作日 |

### 4.2 退款到账时间
| 支付方式 | 到账时间 |
|---------|---------|
| 支付宝/微信 | 1-3个工作日 |
| 银行卡 | 3-7个工作日 |
| 账户余额 | 即时到账 |

## 五、售后申请时效

### 5.1 售后申请时限
| 商品类型 | 售后时限 |
|---------|---------|
| 普通商品 | 签收后15天内 |
| 手机数码 | 签收后15天内 |
| 大家电 | 签收后30天内 |
| 虚拟商品 | 以页面标注为准 |

### 5.2 售后处理时效
- 商家需在24小时内审核
- 节假日顺延
- 逾期自动通过
