# 跨境购物规则

## 一、跨境购物模式

### 1.1 购物方式
| 类型 | 发货地 | 时效 | 税费 |
|------|-------|------|------|
| 海外直邮 | 海外仓库 | 7-15天 | 可能含关税 |
| 保税仓发货 | 国内保税区 | 3-7天 | 已含关税 |
| 跨境拼单 | 多客户拼单 | 10-20天 | 已含关税 |

### 1.2 税费说明
- 跨境商品需缴纳关税
- 单次交易限值5000元
- 年度交易限值26000元
- 税率视商品而定（10-20%）

## 二、清关与认证

### 2.1 实名认证
- 购买跨境商品需实名认证
- 需提供真实姓名和身份证号
- 认证信息仅用于清关

### 2.2 清关流程
```
下单 → 支付 → 申报信息 → 海关审核 → 缴纳税费 → 配送
```

### 2.3 清关时间
- 正常清关：1-3个工作日
- 海关查验：3-5个工作日
- 节假日顺延

## 三、商品限制

### 3.1 限值商品
| 类型 | 限制 |
|------|------|
| 食品 | 部分不可进口 |
| 药品 | 禁止个人进口 |
| 化妆品 | 有成分限制 |
| 电器 | 有安全标准 |

### 3.2 禁运商品
| 类型 | 说明 |
|------|------|
| 违禁品 | 禁止入境 |
| 侵权商品 | 侵犯知识产权 |
| 野生动物制品 | 禁止入境 |

## 四、退货与售后

### 4.1 退货规则
| 类型 | 退货规则 | 运费 |
|------|---------|------|
| 海外直邮 | 7天无理由 | 用户承担 |
| 保税仓 | 支持退货 | 用户承担 |
| 定制商品 | 不支持 | - |

### 4.2 退货流程
1. 申请退货
2. 寄回国内退货仓库
3. 仓库签收后退款
4. 保税区商品退保税区

### 4.3 退款金额
- 退还商品实际支付金额
- 关税按比例退还
- 运费不予退还

## 五、特殊说明

### 5.1 价格说明
- 商品价格含关税
- 可能需支付额外清关费
- 价格以购买时为准

### 5.2 售后服务
- 由平台/商家提供
- 部分商品国内无保修
- 需联系客服协助处理
