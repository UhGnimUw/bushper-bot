# 禁售商品规则

## 一、绝对禁售商品

### 1.1 违法商品
以下商品绝对禁售，违者永久封店并追究法律责任：
| 类型 | 示例 |
|------|------|
| 毒品/易制毒化学品 | 大麻、海洛因等 |
| 枪支弹药 | 仿真枪、气枪等 |
| 管制刀具 | 弹簧刀、军刀等 |
| 爆炸物 | 雷管、炸药等 |
| 色情制品 | 淫秽物品等 |

### 1.2 假冒商品
- 假冒注册商标商品
- 盗版书籍/音像制品
- 假冒伪劣产品
- 侵犯专利商品

### 1.3 走私商品
- 走私车辆/配件
- 走私电子产品
- 未经报关进口商品
- 水货/来路不明商品

## 二、限制销售商品

### 2.1 需要资质的商品
| 商品类型 | 所需资质 |
|---------|---------|
| 食品 | 食品经营许可证 |
| 药品 | 药品经营许可证 |
| 医疗器械 | 医疗器械经营许可证 |
| 化妆品 | 化妆品生产许可证 |
| 图书 | 出版物经营许可证 |

### 2.2 限售商品
| 商品 | 限制条件 |
|------|---------|
| 处方药 | 禁止网络销售 |
| 烟草 | 禁止网络销售 |
| 酒类 | 未成年人不可购买 |
| 刀具 | 刃长超过规定限制 |

### 2.3 限价商品
- 部分商品有政府限价
- 不可哄抬物价
- 不可低于成本价倾销

## 三、医疗药品类

### 3.1 禁止销售
- 处方药禁止销售
- 违禁药品禁止销售
- 野生动物制品禁止销售
- 部分中药材限制销售

### 3.2 需要许可
- 医疗器械需相关资质
- 隐形眼镜/护理液需许可
- 成人用品店需特种经营许可证

### 3.3 夸大宣传
- 不可宣传治疗效果
- 不可虚假医疗功效
- 保健品不可代替药品

## 四、食品饮料类

### 4.1 禁止销售
- 过期食品
- 变质食品
- 三无产品
- 假冒伪劣食品

### 4.2 需要许可
- 预包装食品需SC证
- 特殊食品（保健食品）需蓝帽子
- 婴幼儿配方奶粉需注册

### 4.3 进口食品
- 需有中文标签
- 需有进口检验检疫证明
- 需在海关备案

## 五、化妆品/护肤品

### 5.1 禁止销售
- 过期化妆品
- 自制化妆品
- 未备案化妆品
- 含违禁成分化妆品

### 5.2 特殊化妆品
| 类型 | 要求 |
|------|------|
| 防晒 | 需特殊许可 |
| 美白祛斑 | 需特殊许可 |
| 染发烫发 | 需特殊许可 |
| 脱毛 | 需特殊许可 |

### 5.3 标签要求
- 需有中文标签
- 需标注生产日期/保质期
- 需标注成分表

## 六、图书/音像制品

### 6.1 禁止销售
- 盗版书籍
- 淫秽色情出版物
- 封建迷信出版物
- 非法宗教出版物

### 6.2 限制销售
| 类型 | 要求 |
|------|------|
| 进口图书 | 需版权引进许可 |
| 音像制品 | 需版号 |
| 电子书 | 需版权授权 |

### 6.3 违规处罚
- 违规销售将永久封店
- 涉及违法内容追究刑事责任
- 商家需承担法律责任

## 七、野生动物相关

### 7.1 禁止销售
- 象牙/犀角制品
- 虎骨/熊胆制品
- 珊瑚制品
- 玳瑁/砗磲制品

### 7.2 受保护动物
- 活体野生动物
- 野生动物皮毛/骨骼
- 野生动物药材
- 宠物活体（部分）

### 7.3 举报奖励
发现违规销售可举报：
- 举报有奖
- 举报信息保密
- 重大线索最高奖励万元
