# 积分与成长值规则

## 一、积分获取

### 1.1 购物积分
| 行为 | 积分奖励 | 说明 |
|------|---------|------|
| 订单付款 | 实际支付1元=1积分 | 退款扣除积分 |
| 评价商品 | +10积分 | 每商品限一次 |
| 晒图评价 | +20积分 | 需配实物图 |
| 追评 | +5积分 | 限一次 |

### 1.2 活动积分
| 行为 | 积分奖励 | 说明 |
|------|---------|------|
| 每日签到 | +5积分 | 连续7天额外+10 |
| 分享商品 | +2积分 | 每日限3次 |
| 邀请好友 | +50积分 | 好友首购后发放 |
| 参与活动 | 视活动而定 | 不定时有活动 |

### 1.3 积分扣除
| 场景 | 扣除积分 |
|------|---------|
| 取消订单 | 扣除对应积分 |
| 退货退款 | 扣除对应积分 |
| 评价删除 | 扣除获得积分 |
| 违规处罚 | 扣除相应积分 |

## 二、积分使用

### 2.1 使用比例
- 100积分=1元
- 可抵扣部分商品价格
- 不可抵扣运费
- 不可提现

### 2.2 使用限制
- 部分商品不可使用积分
- 部分活动不可使用积分
- 积分不可转让给他人
- 积分不可混合使用

### 2.3 积分过期
- 积分有效期24个月
- 每年12月31日清零
- 账户注销后积分清零

## 三、成长值获取

### 3.1 成长值获取方式
| 行为 | 成长值 | 说明 |
|------|-------|------|
| 订单付款 | 实际支付1元=1成长值 | 退款扣除 |
| 评价订单 | +20成长值 | 每订单限一次 |
| 完善资料 | +10成长值 | 限首次 |
| 每日签到 | +5成长值 | 连续签到额外奖励 |

### 3.2 成长值用途
- 成长值用于会员等级晋升
- 成长值越高会员等级越高
- 成长值不扣除（等级内）

## 四、会员等级

### 4.1 等级划分
| 等级 | 成长值要求 | 标识 |
|------|-----------|------|
| 普通会员 | 0-999 | 无 |
| 银卡会员 | 1000-4999 | 银色 |
| 金卡会员 | 5000-9999 | 金色 |
| 黑金会员 | 10000+ | 黑色 |

### 4.2 等级权益
| 权益 | 普通 | 银卡 | 金卡 | 黑金 |
|------|------|------|------|------|
| 折扣 | 无 | 95折 | 9折 | 85折 |
| 包邮门槛 | 99 | 79 | 59 | 全免 |
| 专属客服 | 否 | 是 | 是 | 专属 |
| 生日礼包 | 无 | 有 | 有 | 专属 |

### 4.3 等级有效期
- 等级有效期24个月
- 到期前12个月需续期
- 未达标则降级
