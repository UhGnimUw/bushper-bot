# 退换货流程详解

## 一、退换货入口

### 1.1 申请入口
- APP：我的→全部订单→订单详情→申请售后
- 网页：我的订单→订单详情→申请退换货
- 联系客服代为申请

### 1.2 申请时限
| 商品类型 | 退货时限 | 换货时限 |
|---------|---------|---------|
| 普通商品 | 7天 | 15天 |
| 手机数码 | 7天 | 15天 |
| 大家电 | 7天 | 30天 |
| 服装鞋帽 | 7天 | 15天 |

### 1.3 申请状态
| 状态 | 说明 |
|------|------|
| 待审核 | 商家尚未处理 |
| 审核通过 | 已通过等待退货 |
| 审核拒绝 | 商家拒绝可申诉 |
| 已退货 | 商家已收货处理中 |
| 已退款 | 退款完成 |
| 已换货 | 换货发出 |

## 二、退货流程

### 2.1 退货步骤
```
申请退货 → 商家审核 → 通过后寄回 → 商家收货 → 退款到账
```

### 2.2 退货审核
- 商家需在24小时内审核
- 节假日顺延
- 逾期自动通过

### 2.3 退货寄送
- 审核通过后获取退货地址
- 填写快递单号
- 退货运费由责任方承担

### 2.4 退款到账
| 支付方式 | 退款到账 | 时限 |
|---------|---------|------|
| 支付宝/微信 | 原路返回 | 3-5天 |
| 银行卡 | 原卡返回 | 3-7天 |
| 余额 | 即时到账 | 即时 |

## 三、换货流程

### 3.1 换货步骤
```
申请换货 → 商家审核 → 通过后寄回 → 商家收货 → 重新发货
```

### 3.2 换货说明
- 换货仅限同款商品
- 可更换颜色/尺码/规格
- 换货后重新计算保修期

### 3.3 换货运费
| 原因 | 运费承担 |
|------|---------|
| 商品质量问题 | 商家承担 |
| 商家发错货 | 商家承担 |
| 用户主观换货 | 用户承担 |

## 四、上门取件

### 4.1 支持城市
- 全国大部分一二线城市
- 部分三四线城市逐步开通
- 以实际显示为准

### 4.2 取件费用
| 原因 | 费用 |
|------|------|
| 质量问题取件 | 免费 |
| 7天无理由取件 | 用户承担 |
| 换货取件 | 视情况而定 |

### 4.3 预约时间
- 可预约3天内的时间
- 时段可选：上午/下午
- 师傅上门前会电话确认

## 五、退货包裹要求

### 5.1 包装要求
- 保持商品原有包装
- 商品配件齐全
- 外观无损坏
- 说明书/保修卡齐全

### 5.2 发票/凭证
- 退货时需包含发票
- 如已使用发票需说明
- 赠品需一同退回

### 5.3 特殊情况
| 情况 | 处理方式 |
|------|---------|
| 原包装丢失 | 使用等效包装 |
| 配件不全 | 协商处理 |
| 外观损坏 | 可能扣折旧费 |

## 六、退换货状态查询

### 6.1 查询入口
- APP：我的→退款/售后
- 网页：我的→退款/售后
- 可查看全部退换货记录

### 6.2 状态说明
| 状态 | 说明 |
|------|------|
| 提交申请 | 已提交等待审核 |
| 审核中 | 商家处理中 |
| 已通过 | 可进行下一步 |
| 已拒绝 | 可申诉或重新申请 |
| 已完成 | 流程结束 |

### 6.3 申诉处理
- 对审核结果不满可申诉
- 提交证据材料
- 平台人工仲裁
