# 红包与卡券规则

## 一、红包类型

### 1.1 红包分类
| 类型 | 获取方式 | 使用条件 | 有效期 |
|------|---------|---------|-------|
| 平台红包 | 活动领取/赠送 | 全平台通用 | 7-30天 |
| 店铺红包 | 商家发放 | 指定店铺 | 7-30天 |
| 现金红包 | 提现/赠送 | 无门槛 | 长期有效 |
| 满减红包 | 活动领取 | 满一定金额 | 7-30天 |

### 1.2 红包获取
- 活动领取
- 商家赠送
- 购买获得
- 积分兑换

### 1.3 红包使用
- 每个订单限用1个红包
- 红包不可拆分使用
- 不可提现（注明可提现除外）
- 不可转让

## 二、红包规则

### 2.1 使用条件
| 条件类型 | 说明 |
|---------|------|
| 订单金额 | 满100可用 |
| 商品范围 | 指定商品/店铺 |
| 使用时间 | 仅限特定时间段 |
| 用户等级 | 会员专享 |

### 2.2 退款规则
| 退款情况 | 红包处理 |
|---------|---------|
| 全额退款 | 红包自动退回 |
| 部分退款 | 红包不退回 |
| 红包过期 | 不予补发 |

### 2.3 红包叠加
- 红包通常不可叠加
- 部分活动可叠加使用
- 店铺红包与平台红包不可叠加

## 三、卡券类型

### 3.1 卡券分类
| 类型 | 特点 | 有效期 |
|------|------|-------|
| 礼品卡 | 可充值 | 永久 |
| 储值卡 | 先储值后消费 | 1-2年 |
| 兑换券 | 兑换指定商品 | 视券而定 |
| 代金券 | 抵用金额 | 1年内 |

### 3.2 礼品卡规则
- 可购买后赠送他人
- 可绑定账户使用
- 可查看使用记录
- 不可提现

### 3.3 兑换券规则
- 兑换指定商品
- 不可折现
- 过期不可使用
- 不可转让

## 四、优惠券规则

### 4.1 优惠券类型
| 类型 | 面值 | 使用条件 |
|------|-----|---------|
| 无门槛券 | 固定金额 | 无门槛 |
| 满减券 | 满100减10 | 满100可用 |
| 折扣券 | 9折/8折 | 视商品而定 |
| 运费券 | 抵运费 | 仅抵运费 |

### 4.2 优惠券使用
- 每个订单限用1张
- 部分商品不可用
- 不可折现
- 不可转让

### 4.3 优惠券过期
- 过期后不可使用
- 过期不补发
- 退款时已用券不补
