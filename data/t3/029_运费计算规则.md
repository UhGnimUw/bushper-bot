# 运费计算规则

## 一、运费计算方式

### 1.1 计费方式
| 计费类型 | 说明 |
|---------|------|
| 按重量计费 | 每1kg为一个计费单位 |
| 按件数计费 | 每件商品独立计费 |
| 按体积计费 | 体积过大按体积重量计费 |
| 固定运费 | 统一运费不按重量 |

### 1.2 运费组成
- 首重费用（1kg以内）
- 续重费用（每增加1kg）
- 特殊地区附加费

### 1.3 首重和续重
| 地区 | 首重费用 | 续重费用 |
|------|---------|---------|
| 大陆地区 | 5-10元 | 2-5元/kg |
| 偏远地区 | 10-15元 | 5-10元/kg |
| 港澳台 | 20-30元 | 10-15元/kg |

## 二、包邮政策

### 2.1 包邮条件
| 会员等级 | 全场包邮门槛 |
|---------|------------|
| 普通会员 | 99元 |
| 银卡会员 | 79元 |
| 金卡会员 | 59元 |
| 黑金会员 | 全场包邮 |

### 2.2 部分商品包邮
- 大件商品单独包邮规则
- 部分活动商品限时包邮
- 商家承诺包邮的商品

### 2.3 不包邮商品
- 大件家具/家电
- 生鲜冷冻商品
- 部分特殊商品

## 三、特殊地区运费

### 3.1 偏远地区
| 地区类型 | 附加费 |
|---------|-------|
| 新疆/西藏 | +10-20元 |
| 青海/宁夏 | +5-10元 |
| 内蒙古 | +5-10元 |
| 港澳台 | +30-50元 |

### 3.2 疫情影响地区
- 因疫情管控可能暂停配送
- 运费以实际下单时为准
- 商家可能承担额外运费

## 四、运费计算示例

### 4.1 普通商品计算
商品重量2kg，大陆地区：
- 首重1kg：6元
- 续重1kg：3元
- 合计：9元

### 4.2 订单满包邮
订单金额100元 + 商品2kg：
- 商品价格满99元包邮
- 无需支付运费

### 4.3 部分商品包邮
订单中A商品包邮，B商品不包邮：
- A商品免运费
- B商品按重量计算运费

## 五、运费退还

### 5.1 退货退款运费
| 退货原因 | 运费退还 |
|---------|---------|
| 商家发错货 | 商家承担 |
| 商品质量问题 | 商家承担 |
| 7天无理由 | 用户承担 |
| 物流损坏 | 商家承担 |

### 5.2 拒收运费
- 非用户原因拒收：商家承担
- 用户原因拒收：用户承担
- 协商后可补偿部分运费

## 六、运费险

### 6.1 运费险类型
| 类型 | 保费 | 保障 |
|------|-----|------|
| 7天无理由险 | 0.5-1元 | 退货免运费 |
| 退换货险 | 1-2元 | 多次退换 |

### 6.2 运费险理赔
- 退货时先自行垫付运费
- 收到退货后退款至账户
- 部分险可直接抵扣运费
