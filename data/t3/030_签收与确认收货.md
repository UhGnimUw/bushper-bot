# 签收与确认收货

## 一、签收规则

### 1.1 签收方式
| 签收方式 | 说明 |
|---------|------|
| 本人签收 | 当面验收后签收 |
| 代收签收 | 家人/同事/门卫代收 |
| 快递柜签收 | 放入快递柜即为签收 |
| 自提点签收 | 门店自提点取货 |

### 1.2 签收时效
- 快递柜：通常3天内取出
- 自提点：收到取货码后7天内
- 无人签收会退回

### 1.3 签收责任
- 本人/代收人签收后责任转移
- 建议当面验货
- 发现问题可拒收

## 二、验收规则

### 2.1 验收流程
```
收到包裹 → 检查外包装 → 验货 → 确认签收
```

### 2.2 验收内容
| 检查项 | 说明 |
|-------|------|
| 外包装 | 是否破损/变形 |
| 商品数量 | 与订单是否一致 |
| 商品外观 | 是否损坏/污渍 |
| 规格型号 | 是否与订单一致 |

### 2.3 异常处理
| 异常情况 | 处理方式 |
|---------|---------|
| 包装破损 | 拍照留证，拒收 |
| 商品少件 | 拍照留证，联系客服 |
| 商品损坏 | 拍照留证，拒收 |
| 型号错误 | 拍照留证，联系客服 |

## 三、自动确认收货

### 3.1 自动确认时间
| 物流状态 | 自动确认时间 |
|---------|------------|
| 显示签收 | 15天后 |
| 显示签收(偏远) | 20天后 |
| 未显示签收 | 30天后 |

### 3.2 延长确认
- 未收到货可在15天内申请延长
- 最多延长至30天
- 申请后商家确认生效

### 3.3 特殊情况
- 物流异常可延长确认时间
- 商家原因导致未收货可投诉
- 虚假签收可申诉

## 四、确认收货后售后

### 4.1 确认收货后售后
| 商品类型 | 售后时限 |
|---------|---------|
| 普通商品 | 确认收货15天内 |
| 手机数码 | 确认收货15天内 |
| 大家电 | 确认收货30天内 |
| 定制商品 | 不支持 |

### 4.2 确认收货后退货
- 在售后时限内可申请退货
- 部分商品可能不支持
- 退货流程同正常退货

## 五、异常签收

### 5.1 未收到货显示签收
1. 联系快递公司核实
2. 联系商家说明情况
3. 申请平台介入
4. 可申请退款或补发

### 5.2 快递柜/驿站签收但未取
- 取货码收到后7天内取出
- 逾期可能退回需重新下单
- 超时退回可申请补发

### 5.3 代收人签收
- 代收人签收视为本人签收
- 请与代收人确认收货情况
- 纠纷需双方自行解决
