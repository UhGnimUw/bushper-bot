# 价格保护规则

## 一、价格保护概述

### 1.1 价格保护定义
- 购物后如商品降价可申请退差价
- 保障用户购买后的价格权益
- 鼓励用户放心购买

### 1.2 价格保护时限
| 活动类型 | 价格保护期限 | 说明 |
|---------|------------|------|
| 普通商品 | 7天 | 下单后7天内降价可申请 |
| 促销活动 | 活动结束前 | 活动期间降价可申请 |
| 会员专享 | 30天 | 会员商品30天价保 |

## 二、价格保护范围

### 2.1 适用范围
| 类型 | 说明 |
|------|------|
| 同商品降价 | 同一商品价格下调 |
| 优惠券导致降价 | 领取优惠券导致价格变化 |
| 满减活动降价 | 满减门槛降低导致实付减少 |

### 2.2 不适用范围
| 类型 | 说明 |
|------|------|
| 限时抢购 | 特殊活动不支持价保 |
| 秒杀商品 | 低价活动不支持价保 |
| 使用积分购买 | 积分抵扣部分不计入 |
| 部分特殊商品 | 以页面标注为准 |

## 三、差价计算

### 3.1 差价计算方式
差价为：下单价格 - 当前价格

### 3.2 差价退还形式
| 退还方式 | 说明 |
|---------|------|
| 优惠券 | 退还等额优惠券 |
| 余额 | 退还至账户余额 |
| 原路退回 | 退款至支付账户 |

### 3.3 部分差价
- 使用优惠券的部分不计入差价
- 满减活动按比例计算差价
- 赠品价值不计入差价

## 四、申请流程

### 4.1 申请步骤
```
发现降价 → 进入订单申请价保 → 填写降价金额 → 商家审核 → 差价到账
```

### 4.2 审核时间
- 商家需在48小时内审核
- 节假日顺延
- 审核通过后1-3天到账

### 4.3 凭证要求
- 商品页面截图（显示价格）
- 订单页面截图（显示下单价格）
- 如实填写降价金额

## 五、特殊情况

### 5.1 团购/拼单
- 团购价格不参与单品价保
- 拼单成功后的价格保护同普通订单

### 5.2 以旧换新
- 以旧换新订单不参与价保
- 换新商品价格按实际支付计算

### 5.3 秒杀活动
- 秒杀商品不支持价保
- 活动结束后恢复原价销售
