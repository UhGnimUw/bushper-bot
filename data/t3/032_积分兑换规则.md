# 积分兑换规则

## 一、积分获取方式

### 1.1 购物获得
| 行为 | 获得积分 | 说明 |
|------|---------|------|
| 订单付款 | 1元=1积分 | 退款扣除 |
| 评价商品 | +10-20积分 | 每商品限一次 |
| 晒图评价 | +20积分 | 需配图 |
| 追评 | +5积分 | 限一次 |

### 1.2 活动获得
| 行为 | 获得积分 | 说明 |
|------|---------|------|
| 每日签到 | +5积分 | 连续7天额外+10 |
| 分享商品 | +2积分 | 每日限3次 |
| 邀请好友 | +50积分 | 好友首购后 |
| 参与问卷 | +10-50积分 | 不定时活动 |

### 1.3 积分扣除
| 场景 | 扣除积分 |
|------|---------|
| 取消订单 | 扣除对应积分 |
| 退货退款 | 扣除对应积分 |
| 评价删除 | 扣除获得积分 |

## 二、积分使用方式

### 2.1 积分抵现
- 100积分=1元
- 可抵扣部分商品价格
- 不可抵扣运费
- 不可提现

### 2.2 积分兑换礼品
- 可在积分商城兑换商品
- 商品价格用积分全额兑换
- 部分商品需+现金购买
- 兑换后不可退货

### 2.3 积分抽奖
| 活动类型 | 消耗积分 | 奖品 |
|---------|---------|------|
| 大转盘 | 100积分/次 | 积分/优惠券/实物 |
| 刮刮卡 | 50积分/次 | 积分/优惠券 |
| 幸运抽 | 200积分/次 | 大额优惠券/实物 |

## 三、积分商城规则

### 3.1 兑换流程
```
选择商品 → 确认积分 → 提交订单 → 地址确认 → 发放/邮寄
```

### 3.2 兑换限制
- 部分商品限会员等级兑换
- 部分商品限数量兑换
- 积分不足不可兑换

### 3.3 兑换发货
| 商品类型 | 发货时间 | 说明 |
|---------|---------|------|
| 虚拟商品 | 即时到账 | 兑换码/券码 |
| 实物商品 | 7-15天 | 陆续发货 |
| 限量商品 | 按页面说明 | 可能需抢购 |

## 四、积分过期规则

### 4.1 过期时间
- 积分有效期24个月
- 每年12月31日清零两年前积分
- 系统自动清零无需申请

### 4.2 积分查询
- APP：我的→积分明细
- 网页：我的→积分
- 可查看积分来源和消耗

## 五、积分转让

### 5.1 转让规则
- 积分不可转让给他人
- 积分不可合并使用
- 账户积分仅限本账户使用

### 5.2 特殊情况
- 账户注销后积分清零
- 积分不可折现
- 积分不可作为礼品赠送
