# 退换货运费规则

## 一、运费承担原则

### 1.1 商家承担运费
| 情况 | 说明 |
|------|------|
| 商品质量问题 | 商家承担 |
| 商家发错货 | 商家承担 |
| 物流损坏 | 商家承担 |
| 描述与实物不符 | 商家承担 |

### 1.2 用户承担运费
| 情况 | 说明 |
|------|------|
| 7天无理由退货 | 用户承担 |
| 用户原因换货 | 用户承担 |
| 规格/颜色不喜欢 | 用户承担 |
| 冲动购买后悔 | 用户承担 |

### 1.3 特殊情况
| 情况 | 运费处理 |
|------|---------|
| 退货时超重 | 超出部分由商家承担 |
| 退货多件 | 按比例分担 |
| 运费险 | 保险公司承担 |

## 二、运费计算

### 2.1 退货重量
- 按实际退货重量计算
- 商家可要求称重照片
- 争议以快递公司称重为准

### 2.2 运费标准
| 地区 | 退货运费 |
|------|---------|
| 大陆地区 | 6-12元/单 |
| 偏远地区 | 10-20元/单 |
| 港澳台 | 30-50元/单 |

### 2.3 运费上限
- 单次退货运费不超过商品价格10%
- 超出部分可协商
- 部分商品有固定退货运费

## 三、运费补贴

### 3.1 上门取件
| 用户等级 | 补贴政策 |
|---------|---------|
| 普通用户 | 部分商品可申请 |
| 银卡用户 | 部分商品免费 |
| 金卡用户 | 大部分商品免费 |
| 黑金用户 | 全场免费取件(限次数) |

### 3.2 运费险
| 险种 | 保费 | 保障 |
|------|-----|------|
| 7天退货险 | 0.5-1元/单 | 每次退货补贴5-10元 |
| 退换货险 | 1-2元/单 | 每月2次补贴 |

### 3.3 补贴方式
- 退款时直接抵扣运费
- 退款至账户余额
- 部分险赔付至支付宝

## 四、退货打包要求

### 4.1 打包要求
- 使用原包装或等效包装
- 商品需妥善包装防损
- 随商品附上退货单号

### 4.2 打包材料
- 防震泡沫/气泡膜
- 纸箱/快递袋
- 胶带封口
- 退货单外贴

### 4.3 注意事项
- 不要直接在商品上贴快递单
- 易碎品需加固包装
- 液体物品需防漏处理

## 五、运费争议

### 5.1 争议情况
| 争议 | 解决方法 |
|------|---------|
| 商家拒不承担运费 | 申请平台仲裁 |
| 运费计算有误 | 提供快递公司凭证 |
| 超重扣费争议 | 以快递公司称重为准 |

### 5.2 仲裁结果
- 平台仲裁为最终结果
- 商家违规将被处罚
- 用户恶意将受限
