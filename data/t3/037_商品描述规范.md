# 商品描述规范

## 一、基本描述规范

### 1.1 标题规范
| 规范项 | 要求 | 错误示例 |
|-------|------|---------|
| 长度 | 20-50字 | 标题过长超出限制 |
| 内容 | 真实准确 | 与实物不符的描述 |
| 关键词 | 包含品牌/型号/核心卖点 | 堆砌关键词 |
| 格式 | 规范清晰 | 乱用符号/全大写 |

### 1.2 主图规范
| 类型 | 要求 | 数量 |
|------|------|------|
| 主图 | 白底正面实物图 | 至少1张 |
| 细节图 | 展示商品细节 | 3-5张 |
| 场景图 | 使用场景展示 | 1-2张 |

### 1.3 描述内容
| 内容项 | 要求 |
|-------|------|
| 规格参数 | 详细准确 |
| 材质说明 | 如实描述 |
| 功能介绍 | 真实有效 |
| 注意事项 | 明确告知 |

## 二、禁止描述内容

### 2.1 虚假宣传
| 禁止内容 | 示例 |
|---------|------|
| 夸大功效 | 绝对化用语（最好/第一等） |
| 虚假认证 | 伪造专利/获奖信息 |
| 价格欺诈 | 虚构原价/折扣 |
| 假冒品牌 | 假冒他人商标 |

### 2.2 违法内容
| 禁止内容 | 说明 |
|---------|------|
| 违禁物品 | 涉及违法商品描述 |
| 色情低俗 | 不当图文描述 |
| 政治敏感 | 不当政治言论 |
| 虚假信息 | 编造不实信息 |

### 2.3 违规处罚
- 描述不符可投诉
- 虚假宣传将受处罚
- 严重违规下架商品

## 三、价格描述规范

### 3.1 价格标注
| 类型 | 要求 |
|------|------|
| 划线价 | 需真实标注 |
| 活动价 | 需标注活动时间 |
| 会员价 | 需标注会员等级 |

### 3.2 促销标注
| 促销类型 | 标注要求 |
|---------|---------|
| 满减 | 满XX减XX |
| 折扣 | X折起 |
| 赠品 | 买X赠X |

## 四、规格参数规范

### 4.1 参数完整性
- 品牌、型号、规格
- 材质、尺寸、重量
- 产地、生产日期
- 保修信息

### 4.2 参数准确性
- 参数与实物一致
- 避免误导性描述
- 专业术语需规范
