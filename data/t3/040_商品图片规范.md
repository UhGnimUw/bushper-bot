# 商品图片规范

## 一、图片基本要求

### 1.1 图片规格
| 类型 | 尺寸要求 | 格式 |
|------|---------|------|
| 主图 | 800x800像素以上 | JPG/PNG |
| 详情图 | 宽度750像素以上 | JPG/PNG |
| 视频 | 10-30秒 | MP4 |

### 1.2 图片质量
| 要求 | 说明 |
|------|------|
| 清晰度 | 图片清晰不变形 |
| 亮度 | 正常亮度不过曝/欠曝 |
| 颜色 | 真实色彩无色差 |
| 白平衡 | 自然色调 |

## 二、主图规范

### 2.1 主图要求
- 第一张必须白底正面图
- 商品占比85%以上
- 无水印/无边框/无文字
- LOGO统一放置在左上角

### 2.2 主图顺序
1. 白底正面主图
2. 侧面图/背面图
3. 细节图/特写图
4. 场景图（可选）
5. 包装图（可选）

### 2.3 禁止内容
- 他人品牌 LOGO（除授权）
- 二维码/联系方式
- 促销文字/价格
- 虚假效果图

## 三、详情页图片

### 3.1 内容要求
- 商品规格参数表
- 材质/成分说明
- 使用方法/步骤
- 注意事项/警示
- 品牌故事（可选）

### 3.2 图片规范
- 保持风格统一
- 文字清晰可读
- 避免过度修图
- 展示真实商品

## 四、视频规范

### 4.1 视频要求
| 要求 | 说明 |
|------|------|
| 时长 | 10-30秒 |
| 分辨率 | 720P以上 |
| 格式 | MP4 |
| 大小 | 不超过50M |

### 4.2 视频内容
- 商品全景展示
- 核心功能演示
- 使用场景展示
- 细节特写

## 五、违规处罚

### 5.1 图片违规类型
| 违规类型 | 处罚 |
|---------|------|
| 盗用他人图片 | 下架商品+扣分 |
| 虚假效果图 | 下架商品 |
| 包含违禁内容 | 永久封禁 |

### 5.2 举报处理
- 发现盗图可举报
- 举报成功有奖励
- 商家可申诉
