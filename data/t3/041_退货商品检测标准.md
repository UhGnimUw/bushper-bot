# 退货商品检测标准

## 一、商品完好标准

### 1.1 外观检测
| 检测项 | 合格标准 | 不合格情况 |
|-------|---------|-----------|
| 表面 | 无划痕/磨损/污渍 | 有明显使用痕迹 |
| 颜色 | 无褪色/变色 | 颜色与原商品有差异 |
| 形状 | 无变形/破损 | 有挤压/碰撞痕迹 |
| 配件 | 齐全无损坏 | 配件缺失或损坏 |

### 1.2 功能检测
| 商品类型 | 检测功能 | 合格标准 |
|---------|---------|---------|
| 电器 | 开关/操作 | 正常工作 |
| 数码 | 屏幕/按键/摄像头 | 显示正常/功能正常 |
| 服装 | 拉链/纽扣/魔术贴 | 开合顺畅 |
| 鞋类 | 鞋底/鞋面/鞋带 | 完好无损 |

### 1.3 包装检测
| 包装类型 | 合格标准 |
|---------|---------|
| 原厂包装 | 完整未拆封/可复原 |
| 运输包装 | 无破损/可保护商品 |
| 配件包装 | 齐全无破损 |

## 二、影响二次销售判定

### 2.1 不可退货情况
| 商品类型 | 判定标准 |
|---------|---------|
| 贴身衣物 | 已试穿/已洗涤 |
| 化妆品 | 已拆封/已使用 |
| 食品 | 已开封/已过期 |
| 软件/游戏 | 已激活/已下载 |

### 2.2 可协商退货
| 商品类型 | 协商条件 |
|---------|---------|
| 电器类 | 已使用但功能正常 |
| 服装类 | 有试穿痕迹但整洁 |
| 图书 | 有阅读痕迹但完整 |

### 2.3 损耗扣费标准
| 损耗类型 | 扣费标准 |
|---------|---------|
| 外观轻微损耗 | 5-15%商品价格 |
| 外观明显损耗 | 15-30%商品价格 |
| 功能受损 | 30-50%商品价格 |
| 包装缺失 | 10-20%商品价格 |

## 三、检测争议处理

### 3.1 举证要求
| 争议方 | 举证内容 |
|-------|---------|
| 商家 | 商品检测报告/照片 |
| 用户 | 收货时商品完好证明 |

### 3.2 申诉流程
1. 商家说明检测结果
2. 用户提交申诉
3. 平台仲裁审核
4. 仲裁结果执行
