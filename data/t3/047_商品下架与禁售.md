# 商品下架与禁售

## 一、下架类型

### 1.1 主动下架
| 原因 | 说明 |
|------|------|
| 库存不足 | 长期缺货下架 |
| 商品升级 | 旧版下架新版上架 |
| 商家调整 | 商家主动调整 |

### 1.2 被动下架
| 原因 | 说明 |
|------|------|
| 违规下架 | 违反平台规则 |
| 侵权下架 | 侵犯知识产权 |
| 质量问题 | 商品质量不达标 |
| 投诉下架 | 被用户投诉下架 |

### 1.3 强制下架
| 原因 | 说明 |
|------|------|
| 禁售商品 | 法律法规禁止 |
| 假货 | 假冒伪劣商品 |
| 虚假宣传 | 严重违规宣传 |

## 二、下架处理

### 2.1 用户处理
| 情况 | 处理方式 |
|------|---------|
| 已付款未发货 | 全额退款 |
| 已发货运输中 | 签收后退款/拒收 |
| 已签收 | 按退货规则处理 |

### 2.2 赔偿处理
| 下架原因 | 赔偿标准 |
|---------|---------|
| 商家责任 | 退款+补偿 |
| 平台抽检 | 退款+优惠券 |
| 违规处罚 | 不赔偿 |

## 三、禁售商品

### 3.1 绝对禁售
| 类型 | 示例 |
|------|------|
| 毒品 | 各类毒品 |
| 枪支弹药 | 仿真枪/气枪 |
| 色情制品 | 淫秽物品 |
| 假货 | 假冒商品 |

### 3.2 条件禁售
| 类型 | 条件 |
|------|------|
| 药品 | 需许可证 |
| 食品 | 需许可证 |
| 图书 | 需版权授权 |

### 3.3 处罚措施
- 永久封禁店铺
- 扣除保证金
- 追究法律责任
- 公示违规信息

## 四、申诉处理

### 4.1 申诉入口
- 商家后台→违规管理→申诉
- 7天内可申诉
- 提交证据材料

### 4.2 申诉结果
| 结果 | 说明 |
|------|------|
| 申诉通过 | 恢复商品 |
| 申诉驳回 | 维持处罚 |
| 部分通过 | 部分恢复 |
