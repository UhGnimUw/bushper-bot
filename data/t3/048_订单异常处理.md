# 订单异常处理

## 一、订单异常类型

### 1.1 支付异常
| 类型 | 说明 |
|------|------|
| 重复扣款 | 支付多次扣款 |
| 支付失败扣款 | 失败但已扣款 |
| 金额错误 | 扣款与订单不符 |

### 1.2 发货异常
| 类型 | 说明 |
|------|------|
| 虚假发货 | 填写虚假单号 |
| 延迟发货 | 超过48小时未发 |
| 错发漏发 | 商品与订单不符 |

### 1.3 物流异常
| 类型 | 说明 |
|------|------|
| 物流停滞 | 长时间无更新 |
| 物流丢失 | 商品丢失未到 |
| 快递破损 | 包装破损商品损坏 |

## 二、异常处理流程

### 2.1 支付异常
```
发现异常 → 联系客服 → 核实情况 → 退款/补发 → 完成
```

### 2.2 发货异常
```
发现异常 → 申请退款/补发 → 商家处理 → 退款/重新发货 → 完成
```

### 2.3 物流异常
```
发现异常 → 联系快递公司 → 联系商家 → 申请退款/补发 → 完成
```

## 三、赔偿标准

### 3.1 支付赔偿
| 情况 | 赔偿方式 |
|------|---------|
| 重复扣款 | 全额退款+补偿 |
| 支付失败扣款 | 全额退款 |
| 金额错误 | 差额退还 |

### 3.2 发货赔偿
| 情况 | 赔偿方式 |
|------|---------|
| 虚假发货 | 退款+商品价格20%赔偿 |
| 延迟发货 | 订单金额5%补偿 |
| 错发漏发 | 退款/补发+运费 |

### 3.3 物流赔偿
| 情况 | 赔偿方式 |
|------|---------|
| 物流丢失 | 全额退款+补发 |
| 快递破损 | 退款/补发+赔偿 |
| 超时未到 | 订单金额5%补偿 |

## 四、异常申诉

### 4.1 申诉入口
- 订单详情页→申请售后
- 客服热线
- 在线客服

### 4.2 申诉材料
| 材料 | 说明 |
|------|------|
| 截图凭证 | 相关页面截图 |
| 聊天记录 | 与商家沟通记录 |
| 照片/视频 | 商品问题证据 |
| 物流证明 | 快递公司出具证明 |

### 4.3 申诉时限
- 发现问题7天内申诉
- 节假日顺延
- 逾期可能无法处理
