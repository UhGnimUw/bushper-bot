# Skill: 示例技能

## 用途概要
这是一个示例技能，用于展示skill目录的结构和渐进式披露机制。

## 详细说明
当用户询问与示例相关的内容时，此技能会被自动发现并添加到上下文中。
技能开发者可以通过在skill/目录下创建新的文件夹来安装新技能。
每个技能文件夹必须包含SKILL.md文件。

## 使用方法
1. 在skill/目录下创建新文件夹
2. 创建SKILL.md文件
3. 定义触发关键词和详细说明
4. 技能将自动被系统发现
