# Skill: 转换单词为诗词

## 用途概要
当用户请求将单词/关键词创作化为诗词时，自动调用此技能。使用 LLM 生成高质量诗词作品。

## 详细说明

### 触发条件
用户发送的消息包含以下任一意图：
- "帮我写一首诗"、"作诗"、"写诗词"
- "将 [单词] 转换为诗"、"[单词] 可以写成诗吗"
- "根据 [词语] 写一首诗"

### 功能说明
技能调用 `convert_words_to_poetry` 工具，使用 `advanced_llm` 生成诗词。

### 参数说明
| 参数 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| `words` | string | 是 | 核心关键词 | "秋风"、"离别"、"明月" |
| `style` | string | 否 | 风格：古诗/现代诗/抒情诗/豪放派/婉约派 | "古诗" |
| `poetry_format` | string | 否 | 格式：五言绝句/七言绝句/五言律诗/七言律诗/词牌名 | "五言绝句" |

### 使用限制
- 一次请求只处理一个核心主题词
- 支持中英文单词
- 生成结果由 LLM 自动创作，不保证与特定诗词库匹配

### 调用示例
用户输入：「将"秋风"写成七言绝句」

Skill 解析出参数：
- words = "秋风"
- style = "古诗"
- poetry_format = "七言绝句"

工具返回：
```
秋风扫尽黄金叶，孤雁归来夜未央。
万里江天成一色，故园回首路茫茫。
```

### 输出格式
纯诗词文本，每行一句，适当分段。错误时返回错误原因说明。
